# 💗 Animated Heart

A romantic and interactive animated-heart web experience built with **HTML, CSS, and JavaScript**.

The project features a glowing heart that gradually draws itself on the screen, followed by animated messages, floating hearts, sparkles, and interactive buttons.

## ✨ Features

* Smooth heart-drawing animation
* Glowing and pulsing heart effect
* Floating hearts and sparkles
* Interactive **Send Love** button
* Interactive **A Surprise** button
* Animated surprise message
* Responsive design for mobile, tablet, and desktop
* Pure HTML, CSS, and JavaScript
* No external libraries or dependencies

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📱 Responsive Design

The website is designed to provide a smooth experience across:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

The layout, typography, buttons, animations, and heart size automatically adapt to different screen sizes.

## 🎨 Highlights

The main visual effect uses an **SVG heart** combined with CSS stroke animations to create the appearance of the heart being drawn gradually.

JavaScript powers the interactive elements, including the floating hearts and the **Send Love** heart explosion.

## ❤️ Purpose

This project was created as a small interactive digital surprise using simple web technologies and creative animations.
